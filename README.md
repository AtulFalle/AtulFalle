# Hi, I'm Atul Falle 👋

Senior Full-Stack Developer with 8+ years of experience building enterprise web platforms, real-time dashboards, cloud-connected systems, and AI-enabled SaaS workflows. I work mainly with Angular, TypeScript, Node.js, NestJS, MongoDB, PostgreSQL, Docker, CI/CD, Azure, and AWS.

I enjoy turning product ideas into reliable, maintainable applications: clean UI architecture, well-structured APIs, practical database design, and delivery pipelines that help teams ship with confidence.
